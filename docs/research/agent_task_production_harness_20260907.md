# Agent 造题 harness：调研记录与下一阶段目标

> 状态：reference / research；查阅日期：2026-09-07。
> 本文记录公开证据、推断与 proposed 设计，不是实验授权或已实现接口。宏观状态以[项目概要](../../项目概要.md)为准；实施方向见[优化计划](../architecture/pipeline_reconstruction_optimization_plan.md)。

## 研究问题与结论边界

目标是可移植、可复做、持续制造专业、有实质复杂度、可完成且可公平评分的多文件任务的方法。研究对象包括任务质量和完整生产成本，不以 Agent 数量、文件数量、rubric 条目数量或模型排名替代质量。

调研支持工程可行性：独立会话、文件工具、程序调度和有限反馈已有公开实现先例。尚无证据证明将这些部件组合后即可稳定制造本项目要求的职业任务。“多 Agent + 世界生成”本身不是充分的新颖性主张；值得研究的是材料、候选实际工作与评分标准的一致性，以及获得这种一致性的成本。

本次阅读覆盖论文摘要、所列重点方法章节及官方接口文档；未复现实验或安装所述 SDK。论文报告的效果限于其模型、任务和预算，近期预印本不作成熟工程保证。网页可能更新；以下日期是访问日期，不是所有版本的发布日期。

GDPval 的公开评分形式观察仅用于讨论具体、可观察、带权重的标准与工作产品。条目数量和粒度因任务而异；不能假设公开 rubric 均完美或存在固定最佳条目数。其具体题目、文件、rubric 正文、答案和数值不复制进本文或生产输入；仍保持 calibration-only 边界。

## 下一阶段目标（proposed，未实现）

复用现有世界作者、独立挖掘者和文件工具，外层程序管理任务/角色/版本、会话、预算和合法依赖，Agent 请求检查、咨询、返工与提交。首版无需全知总管、通用 Agent 平台、MCP 服务或新评分器。

1. **生产单元**形成候选材料、题干与交付合同。考点、难点和易错点作为生产者意图说明单独保存，不作为已验证事实。
2. **独立试做者**只看候选包，实际交付并保存计算、假设和障碍；不读取作者说明、隐藏世界、监督或 rubric。
3. **编译者**先从候选包独立重建要求、判断与计算依据，再参考本题开发试做成果，必要时对照经过可见性检查的作者说明。读取试做后的编译不称为盲态审查；生产者说明不能把隐藏事实带入监督。
4. **有限返工**依据文件证据提出上游问题。材料或题干改变，使相关下游成果失效，历史证据保留；新版试做使用新上下文。开发试做反馈与冻结后的行为评测分开，不改写旧 scope 的隔离合同。
5. **最终冻结与复核**绑定同版本候选包、监督和 rubric。新会话独立复核不读取作者自评、咨询历史；最终意见不回流本题修到通过。未来运行预算和准入条件另定，不沿用旧批次余额。

## 可复算评分依据（proposed）

编译 Agent 用现有 Python、文件读取和重算工具，从候选材料运行小脚本，交付计算脚本、结果记录与 rubric 关联。记录输入文件哈希与定位、筛选/去重/时间/单位口径、计算方法、结果、精度或容差、适用假设。脚本输出实际算得的结果，不能硬编码期望答案伪装计算。

确定数值、方法正确性与专业解释按可独立观察的成果计分；多种合理口径保留条件结果。公式、布局和输出单元格只有在候选要求中明确规定时才成为义务。计算重放能证明可追踪性，不能证明来源选择和业务口径正确；读同一模型脚本反复运行也不构成独立验证。

工具只反馈可定位的读取、计算和一致性错误，不自动裁定职业真实性。独立试做是可解性证据之一，不是唯一标准答案；一个上游错误不应在相同后果上机械重复扣分。

## 生产能力与复现

- 质量：职业用途、事实与来源、可见义务、条件结论、剩余实质工作和公平计分；未解决专业分歧单列，结论保持 provisional / LLM-proxy。
- 成本：全部尝试、失败、返工、咨询、耗时、可得 token/费用和人工时间；以合格非重复任务为分母，未知费用保留未知。
- 多样性：按职业、工作用途和所需分析观察覆盖；同世界多任务另计世界数，不能作为独立样例膨胀统计。
- 复现：记录输入、方法、工具、环境与模型配置，区分计算重放、同配置重做和第二环境实际复做；不要求随机生成文件逐字一致。
- 共用记忆只包含经整理的通用方法与职业依据；具体案例和诊断留在各自任务中。上下文独立不代表模型错误统计独立，不能按赞同票数替代证据。

后续先明确角色输入输出和试做/编译交接，再实现最小增量，最后在另定范围下观察持续产出。旧批次全部通过不是新方向的前置条件；不以修题重抽消除失败，不自动扩样或开展训练、部署、公开发布。
