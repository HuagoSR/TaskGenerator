# 研究问题：如何自动构造真实且可公平评分的职业任务

> 状态：active；核对日期：2026-09-15。
> 本文解释问题与假设；实验结果见[项目概要](../../项目概要.md)，实施方向见[优化计划](pipeline_reconstruction_optimization_plan.md)。

## 核心问题

能生成多份可打开的文件，不等于能稳定制造真实、有自然复杂度、可解且可公平评分的工作任务。项目研究的是职业任务如何被自动构造，以及质量、生产成本和人工介入的关系；模型区分只作条件充分时的辅助行为证据。

## 诊断能力与实验装置的区分

只有Agent在合法可达的工具流程中读到所需材料，并能保存发现、报告上游问题或结束无修改诊断，才适合评价遗漏和误报。流程要求未配置的咨询或试做时，交接失败不能直接归为语义能力不足；反复重查也可能来自不可满足的工具前提。

诊断集应把预期观察逐项映射到实际材料、角色职责和结果接纳条件。rubric检查不能代替编辑声明或时间关系检查；隐藏答案键和自评pass均不能证明覆盖。保持正确包与缺陷包，分别记录有效修订、新引入问题和实验接线失败。

## 为什么容易造出“围绕答案组织的材料”

- **规范不是现场**：法规说明应该怎样判断，却不包含组织为何产生记录、不同系统为何有口径差、谁需要工作成果。
- **抽象能力不等于情境**：由 skill 或 motif 先拼题，容易得到最典型、最短的案例；文件只为关联而存在。
- **输入与答案同时设计**：生成器容易把分析结论写进状态字段，或让题干逐项提示所有隐藏判断。
- **结构检查不能保证真实**：增加文件/字段配额只会让模型满足更复杂的模板，未必增加职业工作量或判断深度。

World-First 的假设是：先生成自然工作记录，冻结后再由独立 Agent 挖掘任务和重建监督，以减少预设答案对材料的反向塑造。职业对抗难度应改变有因果依据的事实与证据关系，而不是加入谜题、乱码或无依据陷阱。

## 为什么造题研究与有限评分支持需要分开推进

宽泛判断点可能把计算、证据、结论与表达捆绑，导致部分分和重大错误边界模糊。详细 rubric 也可能暗加要求、忽略题干例外，或把“每月正确”检查成“期末正确”。评委之间一致不能证明标准本身公平。

把这类条目改为0或满分并不消除捆绑。需要检验的是独立成果能否分别观察、评分条件是否自洽，以及完整正式rubric能否脱离教师参考独立使用。同样，编辑者声明删除了提示不证明候选输入发生变化；记录彼此数值一致不证明作者在编制时有条件知道所述事实。这些是生成方法的可检验问题，不能靠增加角色数或核验标签直接解决。

在没有人工专家的当前阶段，独立逐项评分只能提供可审计的 LLM proxy，但它至少应先消除整体偏好、顺序效应和隐藏扣分。项目不把评分稳定作为所有生成研究的先决条件，也不把分数自动回流为生成参数。先分别研究 rubric 的候选可见依据、世界材料因果性和可解性；只有在行为证据足够时才解释难度干预和模型区分。评分不确定限制结论，不自动阻断其他研究。

可借鉴 GDPval 的是具体、可观察、带权重的标准及可核验工作产品，不是固定条目数、逐条无误的假设或预期排行榜。GDPval 的具体内容不进入生成链。

## 当前编译假设

先从候选的工作要求推导评分项，再同时确定核验方法，有望改善公平性与可解释性：

1. 不暗加题干未要求、材料也不能合理支持的义务。
2. 少量专业判断可以对应多个独立成果，不机械按比例拆分。
3. 适用条件、例外与替代结论必须对应清楚的得分路径。
4. 等价表达不能取消明确要求；部分分与满分不能相互矛盾。
5. 核验范围与要求一致；无法检查时记录不完整，不猜测或以局部代替全部。

这些是待验证的方法，不是新的业务本体。专业审查允许有分歧；目标是减少可解释的共性错误，而不是追求绝对一致或调整标准迎合排名。

## 下一阶段研究假设（proposed）

正式原子 rubric 的候选义务、满分条件和合理替代路径须可由候选可见材料追溯；教师参考推导及 legacy grader 的整数部分分不能补充或改变这些评分条件。legacy rw-task 作答可暴露交付障碍，但不能替代该公平性检验或专家判断。

独立候选试做与编译者分别建立判断，再通过文件和计算证据处理分歧，可能减少作者意图、实际任务和 rubric 之间的偏离。可复算结果有望改善数值条目的准确性；上下文隔离有望减少上游答案暗示。它们都不是已验证的因果结论，多 Agent 也可能增加重复劳动、成本和共同偏差。

生产者考点与难点仅作为设计假设。编译必须区分候选义务、可替代解法和试做者额外分析；不能根据某一答案反推唯一满分路径。一次成功试做提供一条完成路径，失败还需区分候选能力与题目缺陷。相关研究与适用限制见[调研记录](../research/agent_task_production_harness_20260907.md)。

## 非目标

不手改冻结题目改善成绩，不重抽低分答案，不扩大评测掩盖生成问题，不把静态检查或 LLM proxy 视为专家有效性、训练准入或公开发布资格。
