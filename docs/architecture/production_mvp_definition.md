# Production MVP 与准入语义

> 状态：reference；核对日期：2026-09-11。
> 只定义生产边界；当前 release、结果及停止点见[项目概要](../../项目概要.md)。

## 诊断证据的准入限制

预置合成包用于开发工具，不计自主造题成果或职业质量合格率。工具ready、模型正常完成、控制器接纳和独立复核必须分别记录；批次completed仅指清单处理结束。完整生产前提不满足时，诊断微测不能伪造咨询或试做来获得提交资格。

回归通过只支持实际覆盖的路径；当前32项实际入口夹具已证明诊断到独立复核的结构路径可达，但不证明真实Agent语义能力。启动消耗包含已启动但超时或接纳失败的会话；父子计数按子attempt核对，原历史记录仍保留。

## 已有运行基础

R9 提供 SSH 驱动的内部批处理工厂，不包含公网 API 或控制面板。factory/eval 从确定 Git commit 构建不可变 Linux/amd64 镜像，单并发运行；release 元数据、运行数据与 secrets 分离。

发布须满足：secret-free 构建上下文、断网/只读根/无凭据 parity、工具 smoke、可查询的 current/previous 和回滚路径。发布/激活前磁盘可用空间至少 **95 GiB**。清理范围须单独授权，不触碰其他项目；不默认执行全局清理。

## 四类证据不得混用

| 证据 | 能说明什么 | 不能说明什么 |
| --- | --- | --- |
| 静态准入 | 来源、文件、隔离、引用和交付合同通过检查 | 职业真实性或可解性的完整证明。 |
| 专业审查 | Agent 对内容、监督或 rubric 的代理意见 | 人工专家有效性。 |
| 有效交付 | 模型按合同生成可打开的真实文件 | 业务结论正确。 |
| 行为评测 | 冻结条件下的评分、差异和不确定性 | 普遍模型排名、训练或公开发布资格。 |

`candidate_ready`、`production_ready_for_evaluation` 仅在对应合同与 campaign 的要求内解释；历史 R9/R7 状态不能直接作为 R10 扩题准入。

## R10 研究与生产的边界

R10 使用来源约束的 Work Seed、Rules 与专业 Skill，生成工作世界，独立挖掘任务并重建监督。它复用已有运行基础，但仍属于研究实验，不因某个阶段通过就成为已验证的规模化生产服务。

Rubric V2 是冻结任务的独立派生物。编译与审查通过，只说明生成侧初步可用；实际评分和新增任务需要另设实验。完整性、真实性、可解性、公平评分与区分度应分别报告，不将“格式正确”升级为“任务质量获证”。

历史 R10.11 只用冻结有效交付校准独立逐项评分，不扩题、不重跑 Solver、不部署；任何结果都不自动导出训练集、启动 SFT/RL、公开题库、promotion 或切换默认模型。

## 开发试做与计算依据（首版实现）

造题 harness 在独立上下文中组织生产、开发试做、监督与 rubric 编译、最终复核。开发阶段至多一次上游返工，最终冻结后不把终审意见回流修到通过；旧 scope 的阶段顺序和合同保持兼容。计算脚本在断网、无凭据、只读候选输入中重放，依据记录来源哈希、口径、结果、容差和 rubric 关联；可复算只支持确定性结果与口径追溯，不能替代专业真实性或公平性判断。

2026-09-08链式复验只到达局部阶段，历史状态不变。2026-09-09另定的采购开发scope在计算依据version 2上完成候选材料、独立挖掘、9项33分rubric、一个execution的13个数值锚点、两次一致重放、开发试做、最终提交、独立终审和盲试做。该单题为真实端到端能力提供了初步代理证据，仍不能由一次结构及LLM复核成功推断跨职业或规模化能力。

生产能力须同时报告全部尝试、非重复合格任务、失败/返工成本、人工介入及职业覆盖；同世界多任务单列世界数，不当作独立复验。复杂度看实际证据整合和专业判断，不能由文件数、评分项数或模型耗时直接推断。配置可重做与第二环境实际复现分开解释。旧批次全部通过不再是推进新方向的前提，但新方法质量仍需独立证据，当前不声称量产已获证。

## 评分暂停期间的研究边界

legacy rw-task 适配器提供候选侧输入和旧工具链的受限诊断，不是恢复评分研究或建立排行榜。其结构有效交付、旧 strict 整数分和向下审计必须与正式原子 rubric、职业质量判断和生产准入分开记录；详细结果只在概要维护。

加权二元rubric的结构通过不证明一个条目只含一个成果，也不证明不同条目无重复计分。完整质量准入需正式rubric自身可独立使用、满分条件与合理替代路径一致、材料知识时点有据；教师依据不能补充评分条款。开发/盲试做产生有效交付后仍可因这些问题保留研究者uncertain，原生completed和终审pass分别保留。候选编辑效果按实际可见文件差异计量，内部元数据修改不能直接作为增加判断空间的证据。

任务真实性、材料因果关系、可解性与 rubric 要求追溯可在新的明确范围内继续研究，不要求先完成独立评分系统验收。强弱区分仍是职业任务的一个质量证据，但不能由未经验证的总分或格式合规直接推断。评分不确定时保留不确定性，不自动取得生产、训练或公开发布资格。
